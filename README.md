# Dev UniPiaget

Repositório destinado ao desenvolvimento e armazenamento de projetos, exercícios e atividades acadêmicas do curso de **Análise e Desenvolvimento de Sistemas (ADS)** do Centro Universitário UniPiaget.

## 📚 Sobre o projeto

Este repositório reúne códigos e projetos desenvolvidos durante a graduação, incluindo atividades práticas, exercícios de programação, desenvolvimento web, APIs, banco de dados e outras tecnologias abordadas ao longo do curso.

## 🛠️ Tecnologias

Entre as tecnologias utilizadas nos projetos deste repositório estão:

* JavaScript
* Node.js
* Express
* Python
* MongoDB
* SQL
* HTML
* CSS
* React / React Native
* Git e GitHub

## 🎓 Objetivo

O objetivo deste repositório é organizar os projetos acadêmicos e acompanhar minha evolução no desenvolvimento de software ao longo do curso.
